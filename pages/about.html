Substantial, Decomposable, and Invisible: Visual Context Misalignment in Instructional Videos for Physical Tasks

Yayuan Li*, Chenglin Li*, Jingying Wang, Filippos Bellos, Anhong Guo†, Jason J. Corso†
Full Paper, in submission to UIST 2026
We examine how visual context misalignment in instructional videos affects physical task guidance. Across two studies with 56 participants, we find that in-context instructional videos (ICON), which align with the user's visual perception, improve completion quality, reduce completion time, and lower cognitive load compared with business-as-usual videos. We identify four key visual context attributes and evaluate their individual impacts on task performance and user perception.

RAVEN: Realtime Accessibility in Virtual ENvironments for Blind and Low-Vision People

Xinyun Cao, Kexin Phyllis Ju, Chenglin Li, Venkatesh Potluri, Dhruv Jain
CHI 26 Full Paper, ASSETS 25 Demo (Best Demo Award), CHI 25 Late Breaking Work
In this work, we present RAVEN, a system that responds to query or modification prompts from BLV users to improve the accessibility of a 3D virtual scene at runtime. We evaluated the system with eight BLV people, uncovering key insights into the strengths and shortcomings of generative AI-driven accessibility in virtual 3D environments, pointing to promising results as well as challenges related to system reliability and user trust.
